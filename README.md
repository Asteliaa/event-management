# Event Management

Платформа для управления мероприятиями (конференции, вебинары, встречи).

## ЛР4: состояние в React

Клиент в папке `client/`, данные хранятся в `localStorage`, сервер для этой работы не нужен.
Инструкция и список возможностей: [client/README.md](client/README.md).

```bash
cd client
npm install
npm run dev   # http://localhost:5173
```

Сервер из ЛР1–ЛР3 лежит в корне репозитория, запуск описан в README ветки `lab23`.
