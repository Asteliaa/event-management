# Event Management

Платформа для управления мероприятиями (конференции, вебинары, встречи).

Лабораторные работы по дисциплине ИТиВП. Каждая работа лежит в своей ветке и наращивает предыдущую.
Инструкция запуска находится в README нужной ветки.

| Работа | Ветка | Что сделано |
|---|---|---|
| ЛР1 | [`lab21`](../../tree/lab21) | REST API на Express, данные в памяти |
| ЛР2 | [`lab22`](../../tree/lab22) | PostgreSQL, Sequelize, миграции и сиды |
| ЛР3 | [`lab23`](../../tree/lab23) | JWT, bcrypt, роли, автотесты |
| ЛР4 | [`lab24`](../../tree/lab24) | React-клиент, состояние и `localStorage` |
| ЛР5 | [`lab25`](../../tree/lab25) | Клиент работает с API: axios, оптимистичные обновления, поиск |
| ЛР6 | [`lab26`](../../tree/lab26) | MongoDB и Mongoose, вложенные регистрации |
| ЛР7 | [`lab27`](../../tree/lab27) | Socket.IO: чат мероприятий, уведомления |
| ЛР8 | [`lab28`](../../tree/lab28) | Docker и Docker Compose |

В `main` лежит только каркас проекта.
