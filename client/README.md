# Event Management: клиентская часть (ЛР4)

React-приложение (Vite) для управления списком мероприятий платформы
«Платформа для управления мероприятиями». Данные хранятся в `localStorage`,
сервер не нужен (в ЛР5 хранилище будет заменено на REST API из этого репозитория).

```bash
cd client
npm install
npm run dev     # http://localhost:5173
npm run build
```

Возможности:

- добавление, редактирование и удаление мероприятий (название, тип, дата, вместимость, описание);
- поиск по названию и описанию, фильтр по типу и периоду, сортировка;
- хранение списка в `localStorage` через хук `useLocalStorage`, демо-данные при первом запуске;
- имитация загрузки с сервера (1 с), автосохранение с задержкой 500 мс;
- счетчик мероприятий в `document.title`, статистика по списку.
